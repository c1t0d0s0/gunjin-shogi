# 二十三枚型 軍人将棋（行軍将棋）Webブラウザ版

伝統的なボードゲーム「**軍人将棋（行軍将棋）**」の23枚型を、Webブラウザ上で手軽かつ本格的に楽しめるシングルページWebアプリケーションです。

相手の駒が見えない「**不完全情報（フォグ・オブ・ウォー）**」の心理戦、第三者である「**審判（レフェリー）**」による秘密の勝敗判定、推理AIとの駆け引きを、洗練された和モダンなビジュアルとリアルタイム音響で再現しています。

---

## 🌟 主な特徴

- **公式ルール完全準拠の審判エンジン**
  - 6列×8行盤、突入口2箇所（列1・列4）、総司令部2マス（最奥列中央）。
  - 大将 vs スパイ、工兵・飛行機の地雷撤去、地雷の相打ち爆破、軍旗の背後駒連動、将官・佐官の総司令部占領など、すべてのルールを忠実に判定。
- **フォグ・オブ・ウォー（不完全情報）推論AI**
  - 移動距離、跳躍、戦闘結果の履歴から相手の駒種を確率的に推論する `DeductionTracker` を搭載。
  - **初級**（ランダム要素あり）、**中級**（索敵・司令部強襲）、**上級**（地雷撤去・連携戦術）の3難易度を選択可能。
- **快適な配置＆布陣プリセット**
  - 自陣への自由配置に加え、ワンクリックで適用できる定石プリセット（バランス型・要塞防衛型・電撃速攻型・地雷伏兵型・完全ランダム配置）を収録。
- **戦況をサポートする推理支援メモ**
  - 敵の裏向きの駒をクリックして、推測される候補の確認や自分用の役職マーク（大将？飛行機？等）を付与可能。
- **迫力の審判カットイン演出 & Web Audio プロシージャル音響**
  - 外部音声ファイルへの依存ゼロ。Web Audio APIにより、駒を指す澄んだ木音、和太鼓、鍔迫り合い、爆発、雅楽調の勝利ファンファーレをリアルタイム生成。
- **終局時の種明かし＆感想戦**
  - 勝敗が決した瞬間に相手の駒が一斉に表向きになり、敵の初期配置や進軍ルートを検証可能。
- **完全レスポンシブ対応**
  - PCの大画面からスマートフォンの縦長画面まで、盤面と戦況パネルが崩れず快適に操作可能。

## 📖 ルールと勝敗表

### 1. 駒の構成（各陣営23枚）
| 駒名 | 枚数 | 移動範囲 | 特徴・相性 |
| :--- | :---: | :--- | :--- |
| **大将** | 1 | 前後左右 1マス | 最強。中将以下すべての軍人・飛行機・タンク等に勝利。**スパイと地雷に敗北**。総司令部占領可。 |
| **中将** | 1 | 前後左右 1マス | 大将に次ぐ強さ。大将・地雷以外に全勝。総司令部占領可。 |
| **少将** | 1 | 前後左右 1マス | 大将・中将・地雷以外に全勝。総司令部占領可。 |
| **大佐** | 1 | 前後左右 1マス | 中佐以下・騎兵・工兵・スパイに勝利。飛行機・タンク・地雷に敗北。総司令部占領可。 |
| **中佐** | 1 | 前後左右 1マス | 少佐以下・騎兵・工兵・スパイに勝利。大佐以上に敗北。総司令部占領可。 |
| **少佐** | 1 | 前後左右 1マス | 尉官・騎兵・工兵・スパイに勝利。中佐以上に敗北。総司令部占領可。 |
| **大尉** | 2 | 前後左右 1マス | 中尉・少尉・騎兵・工兵・スパイに勝利。佐官以上に敗北。 |
| **中尉** | 2 | 前後左右 1マス | 少尉・騎兵・工兵・スパイに勝利。大尉以上に敗北。 |
| **少尉** | 2 | 前後左右 1マス | 騎兵・工兵・スパイに勝利。中尉以上に敗北。 |
| **飛行機** | 2 | 前後何マスでも / 左右1マス (跳躍可) | 川・突入口を無視してどこからでも敵陣へ飛翔可能。佐官以下・タンク・地雷に勝利。**将官にのみ撃墜される**。 |
| **タンク** | 2 | 前2マス / 後・横1マス (跳躍不可) | 佐官・尉官・騎兵・スパイに勝利。**将官・飛行機・工兵・地雷に敗北**。 |
| **騎兵** | 1 | 前2マス / 後・横1マス (跳躍不可) | 工兵・スパイに勝利。それ以外に敗北。 |
| **工兵** | 2 | 縦横何マスでも (飛車と同じ、跳躍不可) | **地雷を安全に解体・撤去できる唯一の駒**。タンク・スパイにも勝利。 |
| **スパイ** | 1 | 前後左右 1マス | **大将を唯一暗殺可能**。大将以外のすべての駒に敗北。 |
| **地雷** | 2 | 移動不可 | 接触した敵駒を爆破して相打ち（自身も消滅）。**工兵と飛行機にのみ一方的に撤去される**。突入口に配置禁止。 |
| **軍旗** | 1 | 移動不可 | **すぐ後ろ（自陣側）にある味方駒と同じ戦闘力**を持つ。背後が空なら全敗。突入口に配置禁止。 |

### 2. 勝利条件
1. **総司令部の占領**: 将官（大将・中将・少将）または佐官（大佐・中佐・少佐）が相手の総司令部（最奥列の中央2マス）に突入・制圧した場合。
2. **動ける駒の全滅**: 相手の移動可能な駒がすべて全滅した場合。
3. **（オプション設定）大将討ち取り**: 敵大将を倒した時点で即座に勝利となるローカルルール切替スイッチ。

### 3. 川と突入口（進入制限）
- 地上駒（飛行機以外）が中央の川（Row 3 ↔ Row 4）を越えて敵陣に侵入できるのは、**列1 (Col 1) および 列4 (Col 4) の突入口（橋）** のみです。
- 地雷および軍旗は、突入口マスへの初期配置が禁止されています。

## 💻 開発・実行手順

### 必要環境
- Node.js (v18 以上推奨)
- npm

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```
起動後、ブラウザで `http://localhost:3000` を開きます。

### 3. 自動テストの実行
ルール・相性マトリクス・移動境界・勝利条件のユニットテスト（Vitest）を実行します。
```bash
npm run test
```

### 4. プロダクションビルド
```bash
npm run build
```
`dist/` ディレクトリに最適化された静的ファイルが出力されます。
